# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose users or systems. Contact the repository owner privately through the GitHub profile associated with this repository and include:

- A clear description of the issue.
- Reproduction steps.
- Affected versions.
- Potential impact.
- Suggested remediation, when available.

Please allow reasonable time for investigation and a fix before public disclosure.

## Operational safety

PulseNet performs active network requests. Use port checks and benchmarks only on systems you own or are explicitly authorized to test.
